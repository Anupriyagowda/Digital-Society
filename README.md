# Digital Society Management System

A complete Flask-based digital society management platform with authentication, resident management, billing, complaints, maintenance, security, notices, events, feedback, and simple REST APIs.

## Features
- Authentication and role-based access
- Dashboard with analytics cards
- Resident, complaint, billing, maintenance, security, notice, event, and feedback modules
- SQLite database by default

## Installation
1. Create and activate a virtual environment.
2. Install dependencies: `pip install -r requirements.txt`
3. Run the app: `python app.py`
